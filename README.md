# Friends Included Finance

Course homework project for Friends Included Ltd. The application records sales and expenses, supports manager decisions, and calculates project and company results from Supabase data.

## Local development

1. Copy `.env.example` to `.env.local` and enter the required values.
2. Run `npm install`.
3. Run `npm run dev`.

Secrets belong only in `.env.local` locally and in Vercel environment variables after deployment.
